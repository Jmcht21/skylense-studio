Données, confidentialité et stockage

L’application génère les affiches dans le navigateur. Les clés API optionnelles saisies dans les réglages sont conservées uniquement dans le localStorage de l’utilisateur ; elles ne sont pas enregistrées par Skylense Studio.

Les recherches de lieux, tuiles cartographiques, modèles d’altitude et données complémentaires sont transmis aux fournisseurs concernés pour fournir le service. Consultez leurs politiques de confidentialité et leurs conditions d’utilisation.
